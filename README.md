# Website Analysis

# Website Traffic &amp; Engagement Analysis:-
Exploratory data analysis of website traffic data (Google Analytics-style) using Python to understand how users arrive and how they behave 
and which marketing channels perform best.

# Business Questions & Analysis
1. **Traffic Trends:** Sessions and users over time (peaks, drops, growth)
2. **Top Channel:** Which channel brings the most users
3. **Engagement Time:** Which channel keeps users longest
4. **Engagement Rate:** How it varies across channels
5. **Engaged vs Non-Engaged:** Which channels need improvement
6. **Peak Hours:** Best traffic hours for each channel
7. **Correlation:** Relationship between traffic and engagement rate

# Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn
